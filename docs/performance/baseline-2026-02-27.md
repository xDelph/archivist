# Archivist Performance Baseline (2026-02-27)

Environment:
- Backend URL: `https://archivist-backend.vercel.app`
- Probe location observed: `cdg1::iad1` (from `x-vercel-id`)
- Tooling: `curl` wall-clock and TTFB probes

## Summary

- `GET /api/health` is generally fast (`~0.15s` warm, first hit around `0.55s` to `0.87s`).
- `GET /api/record/thread?...` is moderate (`~0.8s` TTFB).
- `GET /api/record/threads?tab=top&limit=200` is slow and stable around `~4.1s` to `~4.5s` TTFB, with occasional first-hit spikes near `~5.9s`.
- `threads` payload size:
  - compressed (`br`): ~`55 KB`
  - uncompressed (`content-length`): ~`254 KB`

Conclusion:
- Infra cold start is not the dominant factor.
- Main bottleneck is dashboard read-path query/transform complexity for `threads`.
